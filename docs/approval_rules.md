# Approval & Review Rules — Wellness Image Agent

Every image generated by `wellness_agent.py` lands in **`output/pending/`**.
A human reviewer must work through this checklist before moving the image to
`output/approved/` (and ultimately scheduling it for publishing).

---

## 1. Text Accuracy ✏️

- [ ] **English quote** is rendered exactly as written in `wellness_bank.json` — no typos,
      no AI rephrasing, no missing words.
- [ ] **Spanish quote** matches its `es` entry exactly — pay attention to accented characters
      (á é í ó ú ü ñ ¿ ¡) and gendered grammar.
- [ ] Brand handle `@wellness` (or your actual handle) is present and spelled correctly.
- [ ] Category label (if visible) is correctly formatted.

## 2. Visual Quality 🎨

- [ ] Image is sharp and high-resolution (no blurriness, pixelation, or artifacts).
- [ ] Text is fully legible on the chosen background — sufficient contrast (WCAG AA minimum).
- [ ] Layout is balanced; no text is cut off at the edges.
- [ ] The overall aesthetic is clean, professional, and on-brand.
- [ ] No watermarks or unintended overlay text from the image generator.

## 3. Brand Safety 🛡️

- [ ] No faces, identifiable people, or copyrightable art reproduced in the image.
- [ ] No violent, political, religious, or culturally insensitive imagery.
- [ ] No medical claims — wellness quotes should be inspirational, not prescriptive
      (e.g., avoid "This cures depression" framing).
- [ ] Colors and mood match the category palette defined in `image_prompts.yaml`.

## 4. Paired Consistency 🔁

- [ ] The EN and ES images for the same quote share the same template / layout style.
- [ ] Both images have the same background / scene type (not one minimalist, one nature).
- [ ] File naming follows the convention: `YYYYMMDD_HHMMSS_category_lang_snippet.png`.

## 5. Accessibility ♿

- [ ] Sufficient color contrast between text and background (aim for 4.5:1 ratio or better).
- [ ] Alt-text is prepared for the post (see Publishing Handoff for guidance).

---

## Decision Matrix

| Outcome | Action |
|---------|--------|
| All checks pass | Move file to `output/approved/`, proceed to Publishing Handoff |
| Minor visual issue (slightly off alignment) | Regenerate with same prompt + `--quote-id` flag |
| Text error | Fix quote in `wellness_bank.json`, regenerate |
| Brand safety concern | Do NOT publish; flag for team discussion |
| Paired images inconsistent | Regenerate both with explicit `--template` flag |

---

## Regeneration Command

```bash
# Regenerate a specific quote (replace ID with actual quote ID)
python agent/wellness_agent.py --quote-id mf-01 --template a

# Dry-run to preview prompts without API calls
python agent/wellness_agent.py --quote-id mf-01 --template a --dry-run
```
